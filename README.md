# SponsorStack

SponsorStack helps creators and talent managers price sponsorships using reach, engagement, deliverables, production effort, usage rights, exclusivity, and urgency. It generates package anchors, a brand pitch, and a downloadable rate card.

## Why buyers pay for it

- Makes hidden licensing and exclusivity value visible.
- Establishes a private negotiation floor before outreach starts.
- Generates three packages and a ready-to-send pitch.
- Runs without an API key and stores no creator data.

## Run locally

```bash
python -m pip install -r requirements.txt
python app.py
```

## Sell it now

Offer a rate-card review to creators, UGC professionals, and boutique talent managers. Suggested starting offers: **$49 rate review**, **$199 branded rate-card setup**, or **$399 white-label calculator** for a creator community.

## Disclaimer

Rates are planning estimates, not guaranteed market prices. Final fees depend on audience fit, conversion history, creative complexity, rights, exclusivity, contract terms, tax, and demand.
